# Find Jobs visual concepts

Three static 1440×900 desktop explorations for design review. They are separate from the production application.

- **Precision workspace**: persistent navigation, dense results, and a role inspection surface that puts the résumé assessment beside the job.
- **Editorial discovery**: publication-inspired hierarchy, one featured opportunity, and a curated grid of roles.
- **AI-first career intelligence**: a résumé assessment as the main focal point, with dimensions, a caveat, and further roles alongside it.

Job titles, employers, locations, seniority, and the cited Re:Build description come from the existing `results.json` catalogue. The 59/100 assessment, 60/57/57 dimensions, and uncertainty language come from the supplied screenshots. The other roles deliberately have no invented match scores. These are composition studies, not interactive product code or validated recommendations.
